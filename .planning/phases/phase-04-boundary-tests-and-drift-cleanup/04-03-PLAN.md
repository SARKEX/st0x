<objective>
DRIFT-01 — Eliminate scattered `TOKENS.find` / `ALL_TOKENS.find` direct lookups across 12 sites in 9 files. Migrate via ts-morph codemod for `.ts` files (`oracleQuotes.ts`, `priceFeeds.ts`, `tradeTransform.ts`, `api/subgraph.ts`); hand-edit `.svelte` files (codemod cannot safely transform Svelte templates per TRADE-01 precedent). Add an ESLint `no-restricted-syntax` rule that bans these direct lookups outside the canonical lookup module (`src/lib/config/tokens.ts`) plus a lint fixture that intentionally violates the rule.

Purpose: Direct `TOKENS.find(t => t.address === x)` only matches the wrapped address variant. Per MEMORY.md, each ST0x token has 3 addresses (wrapped, unwrapped, legacy). Direct-find sites silently miss unwrapped + legacy variants — a low-grade silent breakage class. `getTokenByAnyAddress` handles all 3 variants. Codemod migrates the existing 12 sites; ESLint rule prevents recurrence in new code.

This mirrors TRADE-01 (Phase 2 Plan 02-01) pattern exactly: ts-morph codemod + ESLint `no-restricted-syntax` rule + lint fixture. Codemod-then-lint, not lint-then-fix (D-04b) — the codemod is the one-shot migration; the rule is the recurrence guard.

Output: 1 codemod script (`scripts/codemods/migrate-token-find.ts`); 1 ESLint rule block in `eslint.config.js`; 1 lint fixture (`tests/fixtures/eslint/token-lookup-violation.ts`); 9 modified files (4 `.ts` codemodded + 5 `.svelte` hand-edited); single PR (atomic-flip discipline).
</objective>
